# 청마 건축환경부 법규 레이더 — 공개 웹사이트

**공개 주소:** https://leehonghun.github.io/cheongma-law-portal/

로그인 없이 누구나 접속할 수 있는 건축환경부 업무지원포털의 정적 화면 전용 저장소입니다.

- 웹사이트: index.html
- 배포와 실제 공개 접속 점검: .github/workflows/publish-public-site.yml
- 실제 공개 사이트 브라우저 점검: tests/public_smoke.py
- 내부 법규 수집 프로그램 및 이력: 비공개 저장소 law-radar-v2
- 법규 자동수집과 공개 홈페이지 자동 반영을 연결하려면 비공개 저장소의 Actions Secret PUBLIC_SITE_PAT에 이 저장소 하나만 쓸 수 있는 미세권한 토큰이 필요합니다. 연결 전에는 사용자가 확인한 최신 스냅샷만 공개됩니다.
- 검색·게시판 목록은 법규 개정 확정이 아닙니다. 실무 적용 전 원문, 시행일, 적용대상, 경과규정을 확인해야 합니다.

기존 중복 공식공지 수집기·시범 게시물 파일은 이번 공개 홈페이지에서 사용하지 않아 현재 브랜치에서 정리했습니다. Git 커밋 이력은 보존됩니다.
